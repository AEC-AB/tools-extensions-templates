# Docs routing

Use this skill when you need framework guidance before changing code in the Navisworks Automation Extension template.

## MCP entry points

Use the `extension-docs` MCP tool:

- `operation=index` to list available docs
- `operation=search` with focused queries such as `navisworks selection`, `autofill`, or `args validation`
- `operation=content` with document ids such as `quick-start`, `args-developer-guide`, `cookbook`, `reference`, or `navisworks`

## Suggested reading order

1. `quick-start` for the template shape
2. `navisworks` for platform-specific behavior
3. `args-developer-guide` when changing configuration classes
4. `cookbook` for reusable patterns worth copying
5. `reference` for exact field syntax and validation rules
